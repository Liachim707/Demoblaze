# Demoblaze

## Описание проекта

Проект содержит автоматизированный UI-тест интернет-магазина [DemoBlaze](https://demoblaze.com), написанный на Java с использованием Selenide и JUnit 5.

## Что делает тест

Тест `HomeworkTest.testAddToCartAndPlaceOrder()` выполняет следующий сценарий:

1. Открывает сайт DemoBlaze и входит под пользователем `test`.
2. Добавляет в корзину три товара: Nokia lumia 1520, Iphone 6 32gb и Sony vaio i7.
3. Сохраняет цену каждого товара на его странице.
4. Открывает корзину, проверяет наличие всех трёх товаров и сверяет итоговую сумму.
5. Заполняет форму Place Order и оформляет заказ.
6. Проверяет сумму в окне подтверждения, извлекает ID заказа и выводит его в консоль.
7. Закрывает окно подтверждения и проверяет, что оно исчезло.

## Используемые технологии

- Java 17 или новее
- Gradle (Gradle Wrapper включён в проект)
- JUnit Jupiter 5.10.0
- Selenide 7.7.2

## Как запустить проект

### Требования

Установите JDK 17 или новее. Отдельно устанавливать Gradle не требуется: в проекте есть Gradle Wrapper.

### Запуск в IntelliJ IDEA

1. Клонируйте репозиторий и откройте папку проекта в IntelliJ IDEA.
2. Дождитесь импорта Gradle-зависимостей.
3. Откройте файл `src/test/java/HomeworkTest.java`.
4. Нажмите зелёный значок запуска рядом с методом `testAddToCartAndPlaceOrder` или запустите задачу Gradle `test`.

### Запуск из командной строки

В корневой папке проекта выполните:

**Windows (PowerShell или cmd):**

```bat
gradlew.bat test
```

**Linux / macOS:**

```bash
./gradlew test
```

Gradle загрузит необходимые зависимости, запустит браузер через Selenide и выполнит UI-тест. Для успешного прохождения теста необходим доступ к интернету и доступность сайта DemoBlaze.

## Результаты тестирования

Отчёт Gradle формируется в папке `build/reports/tests/test/`. Основная HTML-страница отчёта — `index.html`.
